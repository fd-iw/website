  • Universal CSS and JavaScript in the assets folder
  • Smooth animations and transitions

📝 How to Add New Pages

Adding a new page is simple:

  1. Create a new folder in your root directory (e.g., /my-page/)
  2. Add an index.html file in that folder
  3. Link to the universal assets: ../assets/style.css and ../assets/script.js
  4. Add a navigation link in the header tabs

💡 All styling and JavaScript functionality will automatically work on your new page!

🛠️ Tech Stack
